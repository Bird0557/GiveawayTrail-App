# Install GivAwayTrail AI

1. Copy `GivAwayTrail-AI-v1.0.0.apk` to an Android phone or tablet.
2. Open the APK on the device.
3. If Android asks, allow APK installation for the file-manager or browser app you used.
4. Tap **Install**, then open **GivAwayTrail AI**.

Requirements:

- Android 7.0 or newer
- An internet connection
- Access to the existing hosted GivAwayTrail AI site

This APK is signed for direct sideloading and testing. It is not signed with a Google Play release key.
